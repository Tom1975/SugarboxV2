Sugarbox changelog
------------------
v2.1.1 -
   * Add VS Code debug adapter (DAP) for Z80/Amstrad CPC development: breakpoints, registers, stack, disassembly and memory read/write, launch & attach modes
   * Add GDB-compatible debug interface
   * Add hexadecimal memory editor and memory video view panel to the debugger
   * Add FDC, Tape, PPI and ASIC debug panels
   * Add remote commands: insertTape, sendKey
   * Add differential snapshot load
   * Fix disassembly view (native view suppressed, correct PC arrow)
   * Fix drag & drop crash on Windows when loading a file during debug
   * Various CI/build fixes

v2.0.4 -
   * Add : Check the proper "speed" limit set

v2.0.3 -
   * Memory debug window added (up to 4)
   * CRTC debug window added

v2.0.2 - (29/11/2023)
   * Change Qt version to 6.5.1. Builds are now 64 bits only
   * Add CSL script support, ans SSM opcodes
   * Add tape counter
   * Add screenshot command
   * Add command line options : -d (debug), -s (csl script), -cfg (configuration), -cart (cartridge to load)

v2.0.1 - (26/05/2023 22:59:26)
   * Add debugger, disassembly feature, register view, memory view
   * Add status toolbar for sound control, tape & disk shortcuts and visualisation

v2.0.0 - (13/04/2023 15:05:07)
   * Initial V2 release, with automatic build
