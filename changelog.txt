Sugarbox changelog
------------------
v2.2.0 -
   * Add SugarboxV2SDL, a SDL3 frontend (Windows, Linux). The Qt binary is renamed SugarboxV2Qt
   * CRTC emulation reworked for the types 0 to 4 (CRTC Compendium, SHAKER, measures on real machines)
   * Gate Array, interrupts and I/O : inks, mode changes, VSYNC and INT timings, PAL and bus conflicts
   * CPC+ / GX4000 : GX4000 console support in the core, ASIC DMA sequencer, malformed cartridges refused
   * Add a model of the CTM644 monitor (horizontal AFC)
   * Tape : new input model and drive start-up, Speedlock loaders fixed
   * Disk : FDC status and FORMAT fixes
   * Add G-Sync mode, paced on the display
   * Snapshots : the real CPC type is saved, CRTC and PSG states fixed
   * Fix : invalid debug requests no longer close the emulator
   * Fix : CSL escape keys, "reset soft", freezes of the tape and snapshot commands
   * Fix : power on no longer leaves the previous picture or colours, sound no longer blocks the emulation
   * Fix : CRTC dialog and debug server, vertical pulse in lines on the CRTC 1
   * Fix : the version given by the release build is used

v2.1.1 -
   * Add VS Code debug adapter (DAP) for Z80/Amstrad CPC development: breakpoints, registers, stack, disassembly and memory read/write, launch & attach modes
   * Add GDB-compatible debug interface
   * Add hexadecimal memory editor and memory video view panel to the debugger
   * Add FDC, Tape, PPI and ASIC debug panels
   * Add remote commands: insertTape, sendKey
   * Add differential snapshot load
   * Fix disassembly view (native view suppressed, correct PC arrow)
   * Fix drag & drop crash on Windows when loading a file during debug
   * Various CI/build fixes

v2.0.4 -
   * Add : Check the proper "speed" limit set

v2.0.3 -
   * Memory debug window added (up to 4)
   * CRTC debug window added

v2.0.2 - (29/11/2023)
   * Change Qt version to 6.5.1. Builds are now 64 bits only
   * Add CSL script support, ans SSM opcodes
   * Add tape counter
   * Add screenshot command
   * Add command line options : -d (debug), -s (csl script), -cfg (configuration), -cart (cartridge to load)

v2.0.1 - (26/05/2023 22:59:26)
   * Add debugger, disassembly feature, register view, memory view
   * Add status toolbar for sound control, tape & disk shortcuts and visualisation

v2.0.0 - (13/04/2023 15:05:07)
   * Initial V2 release, with automatic build
